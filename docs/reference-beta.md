# Beta Cinemas reference boundary

Checked plan date: 2026-09-22.

The supplied implementation plan records that the public Beta Cinemas site returned HTTP 403 during its survey. This project does not bypass that response, scrape current listings, or ship copied visual identity. The only retained reference is the generic public booking sequence: sign in, select cinema, film, showtime and seats.

Everything shown in CineViet—film names, synopses, cinemas, schedules, prices and CSS thumbnails—is synthetic and labeled DEMO. Before replacing it with externally sourced metadata, record URL, access time, license/permission and a dry-run import report.
